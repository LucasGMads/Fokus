# Fokus

O **Fokus** é uma aplicação de produtividade baseada na técnica Pomodoro, desenvolvida durante um curso de **JavaScript da Alura**.

A aplicação permite alternar entre períodos de foco, descanso curto e descanso longo, utilizando um cronômetro para auxiliar na organização do tempo de estudo ou trabalho.

## Funcionalidades

* Cronômetro para períodos de foco
* Cronômetro para descanso curto
* Cronômetro para descanso longo
* Iniciar e pausar o cronômetro
* Sons para diferentes ações do cronômetro
* Música ambiente
* Alteração do tema de acordo com o período selecionado
* Layout responsivo

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/LucasGMads/Fokus.git
```

2. Entre na pasta do projeto:

```bash
cd Fokus
```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar nenhuma dependência para executar o projeto.
